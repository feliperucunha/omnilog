# Weekly metrics ritual (30 minutes)

Use this cadence from Phase 5 of the scalability roadmap.

## Before the meeting

- Export or open: WAU, signups, activation (first log in 24h), and any revenue (MRR / new subs / churn) from Stripe.
- Skim error volume (Sentry or host logs) for new spikes.

## Agenda

1. **North star (5 min)** — Did it move? Why?
2. **Funnel (10 min)** — Signup → onboarded → first log → returning in 7 days.
3. **Quality (10 min)** — Top crashes, API 5xx rate, slow endpoints.
4. **One bet (5 min)** — Single priority for the next week; everything else is backlog.

## Output

- One line in your changelog or Notion: “Week of YYYY-MM-DD: metric X, decision Y.”

## When to hire

- Only after revenue or funding clearly covers the role; first hire is often **support/community** or **full-stack**, not both.
